How to Generate a UPI QR Code from a VPA

Use a UPI ID to create the payment address inside a UPI QR code, then test the QR before sharing or printing it.

Quick answer

To generate UPI QR code from VPA, enter the receiving payment address in a UPI QR code generator, add the payee name, choose whether to include an amount, and generate the QR. The tool turns those fields into a UPI payment link and encodes it as a QR code.

A VPA is the part that tells the payer's UPI app where the payment should go. The payee name helps the payer recognize the recipient before approving the transaction.

What is a VPA?

VPA means Virtual Payment Address. In everyday UPI usage, people often call it a UPI ID. It usually looks like name@bank, mobile@upi, shopname@provider, or another address format supported by the payment app or bank.

The VPA is commonly placed in the pa field of a UPI payment link. The payee name is placed in the pn field, and INR currency is usually represented by cu=INR. Optional fields can include amount and transaction note.

pa

Payee address, usually the UPI ID that receives the payment.

pn

Payee name, shown so the payer can recognize who they are paying.

am and tn

Optional amount and transaction note for fixed payments or references.

How the VPA becomes a QR code

A UPI QR code usually contains a payment link rather than a bank account number. In a simple payment request, the link starts with upi://pay and includes parameters for the receiving address, payee name, currency, and optional details.

For example, a payment link may include pa=merchant@upi for the receiving address, pn=Merchant%20Name for the display name, and cu=INR for currency. If an amount is included, the link can also include am=500.00. The tool creates this link and then encodes it into the QR image.

Do not guess or invent the payment address. Use the exact receiving UPI ID from your UPI app, bank app, PSP dashboard, or verified merchant account.

Steps to generate UPI QR code from VPA

1. Copy the UPI ID

Copy the receiving UPI ID carefully. Avoid spaces, hidden punctuation, and spelling mistakes.

2. Add a payee name

Use the business, shop, or account holder name the payer should see after scanning.

3. Generate and test

Generate the QR, scan it with a UPI app, and confirm the payment address and name are correct.

If the payment amount changes each time, leave amount blank. If the QR code is for a fixed invoice, fee, or order total, include the amount and a short note.

UPI ID to QR code: static or fixed amount?

A receiving UPI ID can be used in both static and fixed amount QR codes. Static QR codes are reusable because they contain the payment address and payee name but no fixed amount. Fixed amount QR codes add an amount to the payment request.

For a shop counter, a static UPI QR is usually simpler. For an invoice or order total, a fixed amount QR reduces manual typing and makes the payment request clearer.

Why the payee name still matters

Some users assume the UPI ID alone is enough. Technically, the receiving address is the key field, but the visible payee name is important for trust and error checking. A payer should be able to scan the QR and recognize the recipient before entering the UPI PIN.

If you are creating a QR for a business, use the shop or business name consistently. If you are creating a QR for a personal collection, use the name that matches how payers know you.

When app-generated merchant QR is better

A simple QR is useful when you need a readable payment request quickly. A bank app, merchant app, or payment gateway may be better when your business needs verified merchant onboarding, daily settlement reports, refund handling, customer receipts, or automatic order reconciliation.

For counter collection, test the QR in the UPI apps your customers commonly use. App behavior can vary, especially in how much text is shown for notes and payment details.

FAQ

Is VPA the same as UPI ID?

In common UPI usage, yes. VPA and UPI ID often refer to the payment address used to receive UPI payments.

Can I create a UPI QR code from only a VPA?

The VPA is the key field, but you should also add a clear payee name so the payer can verify the payment screen.

Does a VPA QR code need an amount?

No. Leave amount blank for a reusable static QR, or include amount for a fixed payment request.
