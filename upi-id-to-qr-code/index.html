What a UPI ID looks like

A UPI ID, also written as a VPA, is the address money is sent to. It reads like an email handle split by an @ sign, with the bank or app on the right. Examples are priya@okaxis, ravi.kumar@oksbi, or a phone number such as 9876543210@ybl.

The handle on the right tells you which app or bank issued it. Common ones in India include okhdfcbank, okaxis, oksbi, and ybl for PhonePe, along with paytm and apl for other apps. Any valid handle works here, since the code simply carries the address to whichever app the payer scans with.

From address to scannable code

Typing out a VPA at a counter is slow and easy to get wrong. A printed code removes that step: the payer points their camera, the app reads the address, and they only confirm the payment. Nothing about the underlying account changes, so the same code keeps working as long as the ID stays active.

Leave the amount open or fix it

The code made here carries the address with the amount left blank, so the payer types whatever they owe. When the total is known in advance, such as a fixed fee or an invoice, encode the value instead so it shows up ready to confirm.

UPI ID to QR code FAQ

Do I need a new UPI ID to make a code?

No. Use the address you already receive money on. The code carries that same ID to the payer's app.

Which apps can scan the code?

Any UPI app reads it, including Google Pay, PhonePe, Paytm, and BHIM, regardless of which bank issued the ID.

Is my UPI ID stored anywhere?

No. The code is built in your browser. The site does not save the ID, name, note, or the image it produces.
